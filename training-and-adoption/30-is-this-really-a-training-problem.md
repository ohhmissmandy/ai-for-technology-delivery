## Prompt

Review the situation below and determine whether training is actually the problem.

Look for evidence of:

* knowledge or skill gaps
* unclear procedures
* confusing system design
* usability problems
* process problems
* configuration issues
* unclear roles or ownership
* conflicting expectations
* workload or capacity problems
* missing tools or access
* weak manager reinforcement
* support gaps
* resistance to the change

Separate symptoms from likely causes.

For each likely cause, identify:

**Evidence supporting it**

**Evidence against it**

**What we still need to confirm**

**Best response**

If training is part of the solution, explain exactly what people need to learn or practice.

If training is not the main problem, say so and recommend what should be addressed instead.

Do not recommend refresher training simply because users are making mistakes.

## What to provide

Paste the problem being reported, user feedback, support data, examples of errors, current process, training already provided, system behavior, and any other evidence available.

## Example

### Example input

An inventory application launched six weeks ago.

Leadership wants refresher training because users are entering some transactions incorrectly.

What we know:

* most of the errors involve one specific transaction type
* users are completing the other transaction types correctly
* the problem screen has several labels users say are confusing
* the workflow requires users to enter some of the same information twice
* one field sometimes resets after the user moves to the next step
* experienced users and new users are making the same mistakes
* the existing training already demonstrates how to complete this transaction

### Example output excerpt

**Likely diagnosis**

This does not look like a broad training problem.

The strongest evidence points to a combination of usability or process design issues and a possible product defect.

**Evidence against training as the main cause**

* Experienced and new users are making the same mistakes.
* Other workflows covered by the same training are being completed correctly.
* The problem is concentrated in one transaction type.
* The current training already covers the affected workflow.

**What to do next**

* Reproduce and investigate the field-reset behavior.
* Review the confusing labels with actual users.
* Determine whether duplicate entry can be removed or simplified.
* Correct the product or process issue where appropriate.
* Update training only if the final workflow changes or a genuine knowledge gap remains.

More refresher training by itself is unlikely to solve the underlying problem.
