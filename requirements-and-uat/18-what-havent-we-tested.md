# What Haven't We Tested?

Use this when a test plan already exists and you want to find meaningful gaps before testing is considered complete.

## Prompt

Review the requirements, workflows, risks, and current test coverage below.

Identify scenarios that appear to be missing or under-tested.

Look for gaps involving:

* alternate user paths
* exceptions
* error handling
* boundary conditions
* permissions and roles
* unusual but realistic data
* integrations
* handoffs
* timing or sequencing
* duplicate actions
* interruptions or retries
* downstream impacts
* operational support
* high-risk business rules

For each gap, explain:

**What may be missing**

**Why it matters**

**What could go wrong if we don't test it**

**Recommended test scenario**

Prioritize findings based on business impact and likelihood, where the available information supports that judgment.

Do not create obscure edge cases simply to make the test plan longer.

Finish with the highest-priority scenarios that should be added before testing is considered complete.

## What to provide

Paste the current test plan or scenarios along with relevant requirements, workflows, business rules, integrations, risks, or known production conditions.
