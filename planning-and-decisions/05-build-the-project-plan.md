# Build the Project Plan

Use this when the initiative is defined well enough to move from concept into structured delivery.

## Prompt

Build a practical project plan from the information below.

Organize the work into logical phases and include major deliverables, milestones, dependencies, owners or responsible teams, decision points, and target timing.

Show where work can happen in parallel and where one item cannot begin until another is complete.

Call out any dates, estimates, owners, or dependencies that are not supported by enough information yet.

Include a simple milestone view and a detailed work breakdown at the level needed to manage the initiative without creating unnecessary task clutter.

Identify the top planning assumptions and anything that should be validated before the schedule is treated as committed.

## What to provide

Paste the available scope, requirements, dates, dependencies, resources, owners, constraints, and other project information.
